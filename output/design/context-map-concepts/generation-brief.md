# WellBe context map visual studies

Generated using the built-in image generation tool. These are concept images, not validated interaction specifications. No application code or canonical documents changed.

## Shared generation prompt

Use case: ui-mockup. Create a polished high-fidelity visual design concept for WellBe's personal stored-record context map. Landscape image, straight-on screen design, no laptop or device frame. Two large equal side-by-side panels, left 'Full map', right 'Opened record', representing the SAME record graph and same visual design. Generous white/light slate #f8fafc surface, restrained teal #0ea5a4 app accent, dark slate readable sans-serif Figtree-like typography, very minimal app chrome. Small 'WellBe' wordmark, section title 'Context map', helper 'Your records and the links you have kept.' Subtle secondary tabs 'Graph' and active 'Context map', no Home selected.
Semantics: every circle is one stored note, document, result, other record, or capture hub. Color ONLY indicates kind: teal notes, lavender documents, soft blue results, sage other, slate hubs. Include small readable legend. Circle size varies only slightly with number of links. Every circle has a short record title beneath it, with generous separation and no overlaps. Use the SAME 10 sample records in BOTH panels: 'Monday note', 'Visit summary', 'Blood test PDF', 'Sleep note', 'June capture' (hub), 'Prescription scan', 'Questions note', 'Lab attachment', 'Intake form', 'Voice memo'. No symptoms, diagnoses, theories, health scores, risk levels, or causal arrows. Left full graph: all records visible, gently spaced small connected groups plus an isolated record, consistent quiet thin gray links with NO arrows, edges don't pass through unrelated nodes or labels. Right opened view: keep chosen 'Visit summary' roughly at its left-panel relative position; neighbors arranged into available space to its right, previous record 'Monday note' remains behind it, background records faded but visible. Current Visit summary has thin teal selection ring, path from Monday note to Visit summary has a distinct teal line, no arrow or implication of causality. Lines touching current path clear, others faded. Under right map separate tidy button row 'Open r03', 'Open r06', 'Only notes', 'Stop here', 'Clear choice'; neighbor buttons use IDs not record titles. Show small line 'Monday note / Visit summary' as route history. Beneath left 'Choose a record to begin.' At bottom tiny helper 'A line means these records may relate.' Calm, personal, light, open-ended, beautifully legible, thoughtful spacing, screen-design quality. No dark background, no neon, no amber, orange, red, clinical dashboard, metrics, giant central master node, category containers, directional arrows, decorative starfields. Only static concept views; don't show motion trails.

## Direction prompts (summary)

1. Soft glass: translucent sea-glass spherical orbs, diffused highlights, internal gradients, soft contact shadows, spacious organic layout, floating capsule actions.
2. Matte pebbles: softly domed ceramic discs, muted colors, grounded shadows, editorial labels, white canvas, footer actions. The generated output retains more gloss than requested.
3. Fine porcelain: small, near-flat porcelain discs, colored rims, pale interiors, tiny type glyphs, thin neutral links, no enclosing cards, hairline panel divider, outlined footer actions.

## Review limitations

The samples vary some record colors and associations across concepts; treat each as an independent aesthetic study. Soft glass misclassifies Sleep note and Visit summary by color. Matte pebbles fades some direct neighbors too strongly. Fine porcelain is the clearest starting point for labels and kind cues, but the generated record arrangement still needs deterministic implementation to enforce fixed visited positions, one-step navigation, node sizes by degree, and path-only emphasis. Static images cannot verify dragging, reduced motion, keyboard access, or navigation rules.
